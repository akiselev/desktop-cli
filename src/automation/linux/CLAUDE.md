# Linux Automation

Platform-specific Linux automation via AT-SPI2 and X11.

| What | When |
|------|------|
| `atspi.rs` | Implement AT-SPI2 element tree operations |
| `input.rs` | Implement X11 input simulation via enigo |
| `roles.rs` | Map AT-SPI2 roles to UIA control types |
| `screenshot.rs` | Implement screenshot capture via xcap |
| `window.rs` | Implement X11 window enumeration |
| `mod.rs` | Understand Linux module structure |
